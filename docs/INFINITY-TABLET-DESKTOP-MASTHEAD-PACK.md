# PROJECT INFINITY — Tablet desktop masthead pack

- Adds a native Compose wordmark inspired by the supplied desktop reference.
- It appears only on tablet-width desktop surfaces and is hidden while the dashboard is open.
- It is layered above the selected wallpaper; it does not replace or flatten the wallpaper.
- Existing desktop shortcuts, persisted positions, windows, Dock, and phone layout are unchanged.
- This is a progressive visual integration, not a claim that every element in the reference screenshot is complete.
